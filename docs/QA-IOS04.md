# IOS-04: циклы и суперсеты

Пакет реализует один текущий цикл, плановые метки и упорядоченные группы упражнений. Библиотека программ и AI не входят в объём. Серверная часть выпущена первой: [backend workflow 10](https://github.com/nekell3r/podhod-backend/actions/runs/41248140761), commit `5dad7b87157da1e83c79fa461da2e69e3c5cbce4`; race/vet, отдельная PostgreSQL и receipt успешны, SQL fingerprint не менялся. [Контракт](https://github.com/nekell3r/podhod-backend/blob/main/docs/TRAINING-CYCLES-CONTRACT.ru.md).

## Поведение

- Цикл на 2–12 недель из шаблона, понедельник и сохранённый timezone, однократное или повторное применение. Параметры → полный предпросмотр → явное применение. Дни фаз редактируются отдельно, с защитой устаревшего черновика.
- Волна подходов на 4–12 недель: исходное число, +1 до 12, исходное, половина с округлением вверх от 1. Каждая четвёртая и последняя недели разгрузочные. Вес, целевые повторы и фактический запас автоматически не меняются. Правило показано перед применением; персональная рекомендация не заявляется.
- Уже созданная неделя сохраняется. Цикл используется только для отсутствующей недели, не сдвигается из-за пропусков, не переписывает шаблон, активную тренировку или историю. Плановые A/B/C, тип дня и сложность независимы от RIR.
- Суперсет связывает 2–4 упражнения с порядком и отдыхом после круга. В шаблоне число подходов участников меняется вместе. В активной тренировке новая группа включает только оставшиеся подходы с равным количеством; прошлое не переопределяется.
- Добавление круга создаёт все новые подходы атомарно, отдельный подход не включается в группу скрыто. Замена оставляет выполненные связи за исходной карточкой и перенаправляет только будущие. Перестановка карточек не меняет порядок группы.
- Активный роспуск подтверждается и сохраняет выполненные связи/черновики. Пропуск закрывает группу, когда остаётся меньше двух непропущенных участников. Закрытый выполненный подход нельзя разотметить, его RIR можно изменить. Редактор плана меняет черновик до «Сохранить»; «Отмена» его отбрасывает.
- Архив тренировок v6 с точным backup v1–v5 перед первой записью. Цикл, снимки и pending-запрос лежат атомарно в `training.json` текущего аккаунта/гостя. Повтор отправляет прежний requestID/payload/revision, новые правки создают следующий запрос после подтверждения. Старый receipt не понижает revision. Конфликт сохраняет обе стороны и требует выбора.
- `structureVersion:1` сохраняется после очистки метаданных; старые клиенты не могут стереть новые поля полным PUT или через history. Старый JSON без метаданных остаётся без новых ключей. Питание повторно использует тот же типизированный state в `CloudSyncModels.swift`, его JSON-формат не меняется.

## Проверки

Полный локальный core-прогон: 185 тестов, 0 ошибок. После добавления двух сценариев редактирования дня/связанных подходов прошли только эти два; после исправления начального порядка и защиты закрытого круга — один соответствующий новый тест. После ограничения частых проверок изменяемым ресурсом прошёл один новый тест границ шаблона и сохранения маркера. Всего в текущем пакете 189 core-тестов; полный финальный набор выполняет main workflow. Отдельно проверены DST, границы дат/числа фаз, сохранение созданной недели/истории, backup v5, стабильный pending при новых правках, явный конфликт, слоты и UUID, замена, роспуск, удаление с intent и атомарное добавление круга.

UI проверен headless XCUITest только на собственном обычном iPhone 15, iOS 26.5, с синтетическим гостевым архивом. Окно Simulator не открывалось; параллельные устройства/браузеры и локальный Docker не запускались. После каждого прогона собственный симулятор выключен; устройства других проектов не останавливались.

Первый сценарий прошёл параметры, выбор волны, предпросмотр, применение и переходы участников круга, затем выявил автоматический row button style: нажатие «Добавить круг» вызывало также подтверждение роспуска. Этот прогон целиком успешным не считается. Исправлены независимый `borderless` style и области действий от 44 pt. Адресный `testSupersetActionsAndSavedCycleDay` прошёл: добавление не вызывает роспуск, круг увеличивается ровно на один, роспуск подтверждается, закрытая группа отображается, тип дня фазы меняется на «Лёгкий» и сохраняется. Успешные части первого сценария не повторялись.

Сохранённый JSON после UI сверен с синтетическим исходником, UUID сравнивались без учёта регистра: шаблон и история не менялись, session/set UUID и два выполненных подхода сохранились, у каждой карточки четыре подхода, закрытая группа содержит только выполненный круг. Волна сохраняет `[2,3,2,1]`; новая метка дня сохранена рядом с исходным неизменённым pending payload.

Снимки только в игнорируемой `.impeccable/review/`: `ios04-cycle-parameters.png`, `ios04-cycle-preview.png`, `ios04-superset-active.png`, `ios04-superset-actions.png`, `ios04-superset-closed.png`, `ios04-cycle-day-editor.png`. Финальный независимый visual review: `ship` в пределах показанных состояний. Прежнее сокращение navigation title «Состав трениро…» неблокирующее. Сохраняются native SwiftUI формы, тёмные поверхности и lime accent; новых ассетов/визуальной системы нет.

Для воспроизведения используй opt-in `PodhodUIQA`, точный UDID собственного iPhone 15, `-parallel-testing-enabled NO`, одну destination и shutdown после проверки. Первому сценарию нужен синтетический архив без цикла и с открытой группой; адресному продолжению — сохранённый цикл и открытая группа с выполненным первым кругом. Не запускай оба сценария на произвольных пользовательских данных. Xcode может сменить UUID sandbox при установке; путь прошлого запуска нельзя считать актуальным.

## Границы доказательств

Физический iPhone, VoiceOver, максимальный Dynamic Type, браузерный OAuth и синхронизация двух реально подписанных клиентов не проверялись. Протокол подтверждён core и серверными HTTP/PostgreSQL тестами; гостевые снимки не доказывают сетевой выбор конфликта. Уведомления и Live Activity относятся к IOS-09. Выпуск проверяется отдельно по main workflow, серверному receipt и публичным IPA/SHA-256/source.json.
