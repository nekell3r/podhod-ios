# IOS-08: личные замеры и фотографии

Проверки 1 ноября 2026, только iOS. Backend API и Android не меняются ради приватного архива. [Контракт хранения](BODY-PROGRESS-CONTRACT.ru.md).

## Поведение и сохранность

- Отдельная запись замеров на дату, вес и девять окружностей; пустое поле неизвестно. График выбранного показателя использует только измеренные значения. Редактирование и удаление сверяют исходную запись.
- Системный Photos picker, дата и ракурс, предпросмотр перед сохранением. Импорт строит новую ориентированную sRGB JPEG-копию до 2048 px, проверяет размер и удаляет исходные GPS, EXIF, имя и сведения камеры. Для галереи готовится превью до 400 px; обработка изображений последовательна вне main actor.
- Фото и manifest приватного рабочего каталога используют complete file protection. Фон скрывает содержимое; смена аккаунта закрывает старый store и блокирует поздние импорты. Два снимка для сравнения выбираются явно.
- Сначала атомарный manifest удаления и UUID-журнал, затем удаление файла; незавершённая очистка повторяется явно. Оригинал системной медиатеки и прежние backup не меняются.
- Selector v2 с точной копией v1, возобновляемый перенос гостя по UUID/хешам и атомарный receipt вместе с ротацией гостевого каталога. Подтверждённый subject конкретного входа сохраняется в Keychain: офлайн открывается только соответствующий архив. Новый вход не наследует эту связь.
- На сервер замеры и фото не отправляются. Восстановление зависит от настроек резервного копирования устройства; UI это сообщает.

## Core и сборка

Новые проверки покрывают числа/даты/дубликаты, неизвестные значения, сохранение/перезапуск, устаревший редактор, owner/retired store, повреждённый/будущий архив, недопустимые пути, symlink, откат неуспешной записи, журнал удаления, отсутствующее фото, исходный GPS/ориентацию, ограничение пикселей, маленькое превью и отмену обработки.

После финальных изменений AccountWorkspaces адресно прошли **22 теста, 0 ошибок**: существующие аккаунты, гостевые фотографии, прерванный перенос, изменение гостя, заброшенный перенос другого гостя, подтверждённый receipt при сбое очистки, чужое изменение назначения, ошибочный commit, миграция selector и path traversal. Включена регрессия переноса только питания. Изображения и previews проверены отдельными адресными тестами после исправления allowlist технических полей ImageIO. Полный финальный core-прогон и Release-сборка для устройства выполняются штатным main workflow; успешные полные пакеты локально повторно не запускаются.

## iPhone 15

Только отдельный Podhod iPhone 15 QA, iOS 26.5, headless CoreSimulator/XCUITest. Искусственные цветные изображения и синтетические замеры; реальные фотографии пользователя не используются. Сборки максимум в две задачи, один свой симулятор, выключение в EXIT. Остальные симуляторы и контейнеры не затрагиваются.

Ввод 75,5 кг / 80 см, сохранение, правильные числа в архиве и график подтверждены UI-assertions и capture. Начальные прогоны остановились на селекторах теста (объединённая строка LabeledContent и одноимённая кнопка родительского экрана); они не считаются успешными полными прогонами. После подтверждения замеров они исключены из повторного запуска. Оба искусственных JPEG реально выбраны в системном picker, прошли preview и сохранены с ракурсами спереди/сбоку; точные записи и два файла подтверждены после перезапуска. Затем адресный `testPrivatePhotoComparison` прошёл: **1 тест, 0 ошибок**. Подтверждены два изображения в области сравнения, подтверждённое удаление одной копии и недоступность сравнения при одном снимке. После остановки проверено: один JPEG, пустой журнал удаления, замеры 75,5/80 сохранены. Ошибка первого общего image-count учитывала скрытую родительскую галерею; область сравнения уточнена, успешный импорт не повторялся.

Финальный независимый визуальный review: **disposition: ship**, только шесть предоставленных состояний обычного iPhone 15. Прежние native формы и dark/lime система сохранены. Сокращение заголовка «Новое…» в редакторе фото неблокирующее: дата, ракурс и действие «Сохранить фото» видны.

## Границы подтверждения

Физическая блокировка iPhone, системное резервирование/восстановление, загрузка оригиналов Photos/iCloud и реальный браузерный OAuth не подтверждены Simulator или сборкой. Системная доставка уведомлений не относится к этому пакету. QA-captures, xcresult и искусственные исходники остаются в игнорируемых `.build/` и `.impeccable/review/`.
