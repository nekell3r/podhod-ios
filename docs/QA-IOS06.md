# IOS-06: рецепты, продукты и КБЖУ

Реализованы отдельная вкладка питания, 16 собственных рецептов, категории, поиск по названию/ингредиентам и явным синонимам, фильтры времени/белка/избранного, 24 продукта USDA, инструкции и источники. Две иллюстрации созданы для приложения через встроенный image_gen, без материалов референса; точные промпты и файлы — [NUTRITION-ASSETS.md](NUTRITION-ASSETS.md).

Калькулятор различает количество порций приготовления, массу готового блюда, съеденные порции и граммы. После изменения количества приготовления масса требует явного подтверждения. Калорийность берётся из источника; отсутствие нутриента не превращается в ноль. Вода и соль имеют явные исходные нули. Округление выполняется только для отображения. Сырые и готовые продукты остаются разными записями.

## Проверки

- 15 новых Swift-тестов: значения реального каталога; энергия масла без подмены 4/9/4; точность сумм; граммы/дробные порции; масштаб ингредиентов; изменение готовой массы без выдуманных калорий; неизвестные данные, недопустимые числа и переполнение; источники, схемы и ссылки; поиск и фильтры; сохранение/удаление избранного; повреждённый/новый формат; неизвестные ID; ошибка записи; общий лимит; отдельные аккаунты, перенос гостя и legacy-backup.
- Пять существующих тестов AccountWorkspaces также прошли. После поздних изменений выполнялись только новый тест лимита и новый тест синонимов, успешный основной набор не повторялся.
- Семь backend Python-проверок импорта и Python-проверка iOS lock/asset прошли. Импорт закреплён на backend `6cd6ff2838c2b3ebbf5261b94e9d798e4c31c2f1`, версия `2026.10.31.2`; его deploy workflow завершился успешно. Контракт API дневника согласован, сами личные маршруты этим пакетом не добавлены.
- Сборка iOS Simulator arm64 прошла с ограничением двух задач. Сборка устройства и полный release-набор выполняются main workflow.

## Единственный UI-прогон

Обычный iPhone 15 Simulator, iOS 26.5, прежнее отдельное тестовое устройство с синтетической историей. Проверены открытие вкладки и изображения, поиск «миндаль», добавление рецепта в избранное, увеличение приготовления до 1,5 порции, ввод готовой массы 472,5 г с запятой и подтверждение. Для йогурта с бананом и миндалём 150 г дали 146 ккал, на одну порцию — 306,6 ккал. Цифровая клавиатура закрывается штатной кнопкой.

Проверены фильтр избранного, открытие справочника с раздельными сырой/готовой грудкой, поиск масла, избранный продукт и расчёт 10 г масла: 88,4 ккал и 10 г жира. На диске проверены оба избранных ID в отдельном `nutrition-preferences.json`; шесть тренировочных снимков полностью совпали с исходными UUID/подходами/запасом/заметками. Симулятор выключен. Другие модели не запускались.

Локальные снимки: `.impeccable/review/ios06-library-iphone15.png`, `ios06-calculator-iphone15.png`, `ios06-product-iphone15.png`. После них сокращены две подписи без изменения компоновки, уточнён вывод FDC ID и добавлены поисковые aliases, проверенные новым domain-тестом; повторного UI-цикла не было. Независимый review по коду и этим снимкам не выявил оставшихся material blockers после reimport каталога с aliases.

## Границы пакета

Избранное пока локальное, изолировано по аккаунтам; UI сообщает это явно. IOS-07 — дневник, свои рецепты, ручные цели и синхронизация — следующий пакет, его контракт подтверждён пользователем. Добавление еды не имитируется протеиновыми отметками. Физический iPhone, максимальный Dynamic Type, озвучивание VoiceOver, браузерный OAuth и доставка уведомлений здесь не проверялись.
