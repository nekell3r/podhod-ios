# IOS-10: база знаний и сохранённая техника

Проверено 1 ноября 2026, только iOS. [Материалы и контракт сохранённого](KNOWLEDGE-CONTENT.ru.md). Backend/SQL/Android ради этого пакета не меняются.

## Реализация

Шесть собственных материалов с источниками, частыми ошибками и поиском по тексту/тегам. Три проверенных первичных источника — исследования RIR/отдыха и ACSM 2026; остальные тексты объясняют фактические операции приложения. Техника — существующий лицензированный каталог из 58 упражнений. Канонические UUID и сведения авторов/лицензий сохранены, внешние видео не переносятся в AVPlayer.

Закладка доступна в материале, карточке техники и её открытии из рабочей тренировки/программы. «Сохранённое» объединяет оба типа и поддерживает поиск. Новый `knowledge-bookmarks.json` отделён по аккаунтам/гостю; неизвестные ID остаются в файле. Он включён в backup/перенос, поздние действия старого store блокируются, облачная синхронизация не заявлена.

## Проверки

**31 адресный core-тест, 0 ошибок**: 9 новых проверок каталога/поиска и сохранённого плюс 22 затронутых сценария AccountWorkspaces/питания/фото. Покрыты direct decode/будущий формат, небезопасные source URL, дубликаты, регистр/е/ё, неизвестные материалы, сохранение/перезапуск, owner/retire, отсутствие записи при неизменном файле перед commit, лимит/ошибочный ID, отказ записи и гостевая изоляция. Успешные полные пакеты локально не повторялись; полный итоговый core и Release выполняет штатный main workflow.

Debug build-for-testing успешен с максимум двумя задачами. Один headless iPhone 15 QA, iOS 26.5, синтетический guest-архив; Simulator.app, видимые браузеры и другие модели не запускались. Собственный симулятор выключен.

`testSearchSourcesAndSavedTechniqueSurviveRestart`: **1 тест, 0 ошибок**. Открытие базы, поиск «запас», чтение/сохранение материала RIR, видимый первичный источник; поиск «жим», карточка и закладка канонического жима, видимые автор sistab2/лицензия CC-BY-SA 3; оба типа в «Сохранённом» и после перезапуска. Сверены записи файла. В одном source capture виден разрешённый встроенный ролик Goulart/CC BY-SA 4.0; при закрытии прежний player останавливается. Внешний браузер не открывался.

Первый запуск обнаружил неактивную пустую середину новой кнопки: добавлена contentShape всей строки. Незавершённый Knowledge-сценарий повторён после исправления. Отдельно успешный RIR не повторялся. Снимок «Сохранённое» показывает штатное состояние активного поля поиска с клавиатурой, а не обещает полный снимок страницы.

## Границы

Независимый визуальный review семи captures: **disposition: ship** в пределах обычного iPhone 15. Прежняя native dark/lime система сохранена. Снимок сохранённого намеренно показывает активное состояние поиска; физические и дополнительные матрицы не выдаются за проверенные.

Физический iPhone, VoiceOver и максимальный Dynamic Type вручную не проверены. OAuth/аккаунты не создавались, серверные личные данные не менялись; owner/guest проверены изолированными core-архивами. Ссылки источников исследованы отдельно; UI-тест не открывал все сторонние страницы. Рекомендации источников ограничены их областью и датой, не превращены в автоматическую тренировочную программу. Captures, xcresult и синтетические архивы игнорируются Git.
